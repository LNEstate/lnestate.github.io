Privacy policy — LN Mail Summary

Last updated: 14 October 2026.

LN Mail Summary is used only by its owner, Lina Nekrasova, for her own Gmail mailboxes.

What data is accessed

With the owner's consent, the app reads email messages and settings through the Gmail API using the read-only scope https://www.googleapis.com/auth/gmail.readonly.

How data is used

The data is used only to build a private digest of important messages for the owner. The app does not send, delete or modify email.

Sharing

Data is not sold, shared with third parties, or used for advertising. It is not used to train AI models.

Storage and deletion

Access tokens and the digest are stored on the owner's private server with restricted file permissions. The owner can revoke access at any time at myaccount.google.com/permissions; stored tokens are then deleted.

Google API Services User Data Policy

LN Mail Summary's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
